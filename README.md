# 家庭の常備薬・処方薬の一元管理！期限切れ＆飲み合わせチェッカー

自宅にある常備薬や過去の処方薬の期限管理と、複数の薬を同時に飲む際の注意点を一目でチェックできるツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/household-medicine-expiry-dose-checker/）。
2. 画面の指示に従って操作します。
